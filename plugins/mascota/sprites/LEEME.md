# Dibujos de la mascota

Cada carpeta de acá es una mascota completa. Vienen tres: `sprites_cat`,
`sprites_dog` y `sprites_robot`. Se elige con clic derecho → Mascota.

Para agregar la tuya, creá una carpeta más con esta forma:

    mi_mascota/
    ├── esperando_0.png  esperando_1.png  ...
    ├── pensando_0.png   ...
    ├── permiso_0.png    ...
    ├── listo_0.png      ...
    └── cansado_0.png    (opcional: si falta, se usa esperando)

También vale la forma con subcarpetas: `mi_mascota/pensando/0.png`.

PNG con **fondo transparente**. El tamaño no importa: se escalan a 128 px
de alto con escalado nítido, para que el pixel art no quede borroso.

Un estado sin dibujos muestra un emoji, así que podés completar de a poco.
